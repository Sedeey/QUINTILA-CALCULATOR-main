# QUINTILA CALCULATOR

A responsive calculator with keyboard support, calculation history, and five customizable color themes.

## Run the app

Install the dependencies and start Expo:

```sh
npm install
npm start
```

Use the Expo terminal shortcuts to open the app on web, Android, or iOS. To start the web target directly, run `npm run web`.

## Features

- Addition, subtraction, multiplication, division, percentages, decimals, and parentheses.
- Keyboard input, clear, backspace, and chained calculations.
- Recent calculations and copy-result actions.
- Blue, purple, green, orange, and light themes; the selected theme is saved between visits.
- Responsive layouts and accessible button labels.

The standalone browser version is available at `index.html`.
